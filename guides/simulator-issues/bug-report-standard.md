# Bug Report Standard


Every claimed Sail bug **must** include:

1. **Exact command** to reproduce (copy-pasteable)
2. **Trace quote** — relevant lines from Sail trace log showing failure
3. **Analysis** — why observed behavior contradicts RISC-V spec
4. **Comparison** — if applicable, correct behavior on different config (e.g. RV64 vs RV32)

Missing any = "suspected" not "confirmed."
