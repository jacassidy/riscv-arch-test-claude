# Segment Load vd Constraints


Segment loads use NFIELDS consecutive register groups. vd must leave room:

| Segments | Max vd (EMUL=1) |
| -------- | --------------- |
| 2        | 30              |
| 3        | 29              |
| 4        | 28              |
| 5        | 27              |
| 6        | 26              |
| 7        | 25              |
| 8        | 24              |
