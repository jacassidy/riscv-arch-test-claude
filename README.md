# riscv-arch-test-claude

Claude working files (guides, scripts, tools) for the `riscv-arch-test-cvw` repo.

## Setup

```bash
ln -s $WALLY/addins/riscv-arch-test-claude/CLAUDE.md $WALLY/addins/riscv-arch-test-cvw/CLAUDE.md
```

This symlinks the `CLAUDE.md` into the main repo so Claude Code picks up these guides and workflows when working there.
